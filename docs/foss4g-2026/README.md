# FOSS4G 2026 Hiroshima presentation

**A Self-Hostable Open-Source Geospatial Platform for Small Teams, with Natural Language Querying via MCP**

- [PowerPoint presentation](./geo-base-foss4g-2026.pptx)
- [PDF presentation](./geo-base-foss4g-2026.pdf)
- [Technical companion](./companion.md)
- [Demo reproduction guide](./demo/README.md)

The demonstration uses one 87-feature GeoJSON dataset on one local machine. It demonstrates the implemented Host, See, and Ask path; it is not a benchmark or a claim about production scale, cost, or organizational outcomes.
