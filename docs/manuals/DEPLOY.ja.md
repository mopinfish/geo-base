# デプロイガイド

geo-baseは、API、MCP、管理画面、PostgreSQL/PostGIS、オブジェクトストレージ、Redisを個別にデプロイできます。まずローカルDocker環境で確認し、利用環境に応じたマネージドサービスまたはセルフホスト環境へ置き換えてください。

認証情報はGit外で管理し、各`.env.example`を環境変数一覧として利用します。公開境界でTLSを終端し、DBとストレージへのアクセスを制限し、本番利用前に認証用シークレットを更新してください。リリース前には専用テストDBを使い、[TESTING.ja.md](./TESTING.ja.md)の検査を実行します。

特定クラウド向け設定はここでは規定しません。容量、バックアップ、監視、データ所在地、アクセス制御、復旧要件を組織ごとに確認してください。
